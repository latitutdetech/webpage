# Latitude Technology LLC website

A responsive, one-page static website for Latitude Technology LLC, showcasing FinTrak, FinTransit, and FinLegacy.

## Preview
Open `index.html` in any modern browser. No compilation or dependencies required.

## Publish with Cloudflare Pages
1. Cloudflare dashboard → Workers & Pages → Create application → Pages → Direct Upload.
2. Upload the ZIP archive `latitude-technology-website.zip` (or folder contents if requested).
3. After deployment, open the Pages project → Custom domains → Set up a custom domain → `latitudetechnology.one`.

## Publish through GitHub (recommended for ongoing updates)
1. Upload `index.html` and `README.md` to the `latitutdetech/webpage` repository.
2. Cloudflare dashboard → Workers & Pages → Create application → Pages → Connect to Git.
3. Choose `latitutdetech/webpage`, branch `main`, framework preset `None`, build command blank, output directory `/`.
4. Deploy, then add the custom domain in the project's Custom domains settings.

## Notes
- The site intentionally does not link to private administrative application dashboards.
- The FinLegacy card links to the public kiosk demonstration.
- Update contact email in `index.html` if desired.
- Product descriptions reflect observed functionality; confirm marketing claims before publicly promoting services.
